# OpenLab Website

This is a simple static multi-page website for OpenLab Initiative.

## Edit the site

- Update most text, device cards, marketplace listings, publications, vision items, and team members in `content.js`.
- Update colors, spacing, and layout in `styles.css`.
- Update page structure or navigation in the individual `.html` files.

Because it is static HTML, you can open `index.html` directly in a browser. No build step is required.

## Pages

- `index.html`
- `devices.html`
- `marketplace.html`
- `publications.html`
- `vision.html`
- `team.html`
